# TamperSlop
AI generated Tampermonkey scripts

## Scripts
- **9to5uiuc.js**: Auto-fill 8 hours for Monday-Friday on the UIUC PTR System timesheet with a single click.
- **TimeGem.js**: Get timing and token throughput estimates for Google Gemini.
- **maxiThink.js**: Auto-select 3.5 Flash Think in Gemini Web
- **retroCastSkip.js**: Disable "local on 8s" simulation on weather.com's RetroCast.
- **Limits.js**: Adds live countdowns and token estimates to Gemini usage limits.
